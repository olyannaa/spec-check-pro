# ИИ-ревью технических заданий NET

Предварительное ревью ТЗ на новые потоки и витрины данных продукта NET.

Аналитик вставляет текст задания — агент показывает фрагменты, которые могут быть непонятны разработке, объясняет почему и что уточнить. Итоговое решение о готовности документа остаётся за аналитиком.

Стартовый план команды (1 продакт + 2 AI-инженера): [PLAN.md](./PLAN.md).

Примеры документов от кейсодателя подключаются, когда они появятся. До этого работа идёт по гипотезе шаблона и синтетическим ТЗ.
