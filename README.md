# SpecCheck — ревью ТЗ NET

Чат для предварительного ревью технических заданий на потоки и витрины продукта NET.

Аналитик загружает готовое ТЗ (PDF или текст). Решение проверяет документ по **8 обязательным правилам** и показывает замечания с важностью **HIGH / MEDIUM / LOW**. Текст не исправляет.

Модель: **Qwen**. Если ключа нет, работают шаблон и эвристики — демо не падает.

## Как запустить

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:43142

Опционально, чтобы подключить Qwen:

```bash
# .env.local
OPENAI_API_KEY=...
OPENAI_BASE_URL=https://dashscope-intl.aliyuncs.com/compatible-mode/v1
OPENAI_MODEL=qwen-plus
```

Подойдёт любой OpenAI-compatible endpoint (DashScope, OpenRouter, внутренний контур).

## Что на экране

- Чат: вставил ТЗ или приложил PDF → получил комментарии к местам.
- Кнопка в чате **«Обновить 8 обязательных правил»** — правит чеклист, следующая проверка идёт по новой версии.
- Примеры в сайдбаре: поток GEO, источник MSCP, витрина устройств.
- У каждого замечания: важность, раздел, цитата, почему, что уточнить.
