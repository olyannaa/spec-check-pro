# ИИ-ревью технических заданий NET

Предварительное ревью ТЗ на новые потоки и витрины данных продукта NET.

Аналитик вставляет **уже написанное** ТЗ. Агент с несколькими ролями (разработчик, тестировщик, читатель шаблона) указывает места, которые стоит уточнить. Текст не исправляет. Решение о готовности остаётся за аналитиком.

Стартовый план: [PLAN.md](./PLAN.md).

Модель на тестовом кейсе — любая совместимая (Qwen, Kimi). Confluence и MCP не входят в скоуп. Поля истории изменений документа не ревьюим. Лучше лишняя придирка, чем пропуск.
