# Разбор трёх примеров по шаблону и чеклисту

Примеры из `Тестовые данные для Хакатона.pdf`. Это эталон для прогона: агент должен цепляться к этим местам. Не исправлять текст — только указать фрагмент.

Официальный тест будет на **другой** витрине-агрегате. Этот файл — тренировка.

## Чего агент не должен делать на этих файлах

- Не предлагать готовый DDL и не переписывать абзацы.
- Не комментировать «Историю изменений».
- Не ограничиваться тремя замечаниями: по установке кейсодателя 10–20 находок нормально, пропуск хуже придирки.
